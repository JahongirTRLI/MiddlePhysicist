Задачи для повторения Programming Course

Урок 1: Типы данных, ввод-вывод, условный оператор if

Задача 1.1: Напишите программу, которая запрашивает у пользователя целое трехзначное число и проверяет, является ли сумма его цифр чётной. Выведите соответствующее сообщение.
Задача 1.2: Даны три вещественных числа. Найдите наибольшее из них, используя только условный оператор if-elif-else (без использования встроенной функции max()).
Задача 1.3: Напишите программу, которая определяет, попадает ли точка с координатами (x, y) внутрь круга с радиусом R и центром в начале координат (значения x, y, R вводятся пользователем).

Урок 2: Методы модуля math, генератор range()

Задача 2.1: Используя модуль math, найдите значение выражения √(x2 + y2) для введенных пользователем чисел x и y, округлив результат до 2 знаков после запятой с помощью round().
Задача 2.2: С помощью функции range() выведите на экран все нечетные числа в диапазоне от 1 до 50 включительно в обратном порядке.
Задача 2.3: Вычислите факториал числа N (N вводится пользователем, 1 ≤ N ≤ 10), используя генератор диапазона range() в цикле.

Урок 3: ASCII и Unicode, задачи с библиотекой math

Задача 3.1: Напишите программу, которая принимает символ от пользователя и выводит его код в таблице Unicode (используя функцию ord()), а также проверяет, является ли этот символ заглавной латинской буквой.
Задача 3.2: Дано значение угла в градусах. Используя функции math.sin(), math.cos() и переведя градусы в радианы через math.radians(), выведите значение выражения sin2(α) + cos2(α).
Задача 3.3: Напишите программу, которая находит корни квадратного уравнения ax2 + bx + c = 0. Используйте math.sqrt() для вычисления дискриминанта. Предусмотрите обработку случая, когда дискриминант отрицательный.

Урок 4: Встроенные функции Python, ключевое слово def

Задача 4.1: Напишите функцию is_prime(n), которая принимает целое число n и возвращает True, если оно простое, и False в противном случае.
Задача 4.2: Создайте функцию min_of_three(a, b, c), которая возвращает наименьшее из трех чисел, переданных в качестве аргументов, не используя встроенную функцию min().
Задача 4.3: Напишите функцию power_count(base, exponent), которая вычисляет степень числа с помощью цикла, а затем выведите результат с помощью встроенной функции print() в отформатированном виде.

Урок 5: Списки, индексация, методы списков и срезы

Задача 5.1: Создайте список из 10 целых чисел. С помощью отрицательной индексации выведите элементы списка, начиная с третьего с конца до первого с конца.
Задача 5.2: Дан список чисел. Используя методы append() и pop(), перенесите все отрицательные элементы в новый список, сохранив их порядок, а из исходного удалите их.
Задача 5.3: Напишите программу, которая принимает список чисел и с помощью срезов зеркально разворачивает его центральную часть (все элементы, кроме первого и последнего).
Задача 5.4: Дан список целых чисел. С помощью метода insert() вставьте число 0 на позицию с индексом 2, а затем удалите первое вхождение этого числа с помощью метода remove().
Задача 5.5: Напишите скрипт, который очищает содержимое существующего списка с помощью метода clear() предварительно выведя его длину через встроенную функцию len().
Задача 5.6: Дан список элементов. Используя метод reverse(), измените порядок следования элементов на противоположный, а затем выведите срез списка с шагом 2.
Задача 5.7: Напишите программу, которая с помощью срезов делит введенный список четной длины ровно пополам и меняет получившиеся половины местами.
Задача 5.8: Создайте список из 8 произвольных чисел. Используя отрицательные индексы и срезы, получите подсписок, состоящий из последних четырех элементов в обратном порядке.

Урок 6: Цикл for, break, continue, list comprehension

Задача 6.1: Дан список чисел. Используя цикл for с оператором break, найдите первое попавшееся число, которое делится на 7 без остатка, и выведите его индекс.
Задача 6.2: Напишите программу, которая выводит все числа от 1 до 30, пропуская (с помощью continue) те, которые делятся на 3 или на 5.
Задача 6.3: Используя генератор списков (list comprehension), создайте список квадратов только четных чисел из диапазона от 1 до 20.
Задача 6.4: Дан список строк. С помощью генератора списков создайте новый список, содержащий длины каждой строки из исходного списка.
Задача 6.5: Напишите цикл for с использованием функции enumerate(), который выводит на экран элементы списка вместе с их четными индексами.
Задача 6.6: Используя list comprehension с условием, отфильтруйте из заданного списка чисел все элементы, которые меньше среднего арифметического этого списка.
Задача 6.7: Напишите программу с вложенными циклами for, которая генерирует таблицу умножения в виде двумерного списка (матрицы) размером 5х5.
Задача 6.8: Дан список слов. С помощью генератора списков сформируйте новый список, состоящий только из тех слов, которые начинаются с заглавной буквы «А» или «а».

Урок 7: Строки и методы строк

Задача 7.1: Дана строка-предложение. Напишите программу, которая подсчитывает количество гласных букв в этой строке, используя строковые методы (например, lower() и оператор in).
Задача 7.2: Напишите программу, которая проверяет, является ли введенная строка палиндромом (читается одинаково слева направо и справа налево), предварительно удалив из нее все пробелы и переведя в нижний регистр с помощью методов replace() и lower().
Задача 7.3: Дана строка, состоящая из слов, разделенных пробелами. Преобразуйте строку так, чтобы каждое слово начиналось с заглавной буквы (используйте методы split() и capitalize()).
Задача 7.4: Напишите программу, которая принимает строку и с помощью метода count() определяет, сколько раз в ней встречается заданная пользователем буква.
Задача 7.5: Дана строка с текстом. Используя метод replace(), замените все запрещенные слова (например, список из трех слов) на символ звездочки *.
Задача 7.6: Напишите скрипт, который проверяет введенную пользователем строку с помощью метода isdigit(). Если строка состоит только из цифр, преобразуйте ее в число и найдите сумму ее цифр.
Задача 7.7: Используя методы strip(), lower() и split(), очистите введенную пользователем строку от лишних пробелов по краям и разбейте ее на отдельные слова, выведя их в столбик.
Задача 7.8: Дана строка, содержащая расширение файла (например, "document.tar.gz"). С помощью метода rfind() или split() найдите и выведите основное имя файла и его расширение.
