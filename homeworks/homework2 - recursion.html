Задачи на рекурсию

Сложный уровень школьного курса (профильная информатика, ЕГЭ, начальные олимпиады)

Алгоритмы и теория чисел

Задача 1

Проверка числа на простоту

Условие: Дано натуральное число N (2 ≤ N ≤ 109). Определите с помощью рекурсивной функции с параметром d (текущий делитель), является ли число простым.

Идея: Начинаем проверку с d = 2. Если d * d > N, делителей нет — число простое. Если N % d == 0 — число составное. Иначе вызываем проверку для d + 1.
Задача 2

Разложение на простые множители

Условие: Дано натуральное число N (2 ≤ N ≤ 109). Выведите все его простые делители в порядке неубывания с учётом кратности (например, для 12 вывести 2 2 3).

Идея: Передавайте текущий делитель d (начиная с 2). Если N делится на d, выведите d и вызовите функцию для N / d с тем же d. Иначе переходите к d + 1 (учитывая условие d * d <= N).

Строки и скобочные выражения

Задача 3

Добавление звёздочек между символами

Условие: Дана строка S из латинских букв (длина до 1000). Сформируйте новую строку, вставив символ * между соседними буквами (например, hello → h*e*l*l*o).

Идея: Базовый случай — строка длины 1 (возвращаем саму строку). Шаг рекурсии — берём первый символ S[0], прибавляем "*" и результат функции от среза S[1:].
Задача 4

Вычисление значения арифметического выражения со скобками

Условие: Дана корректная запись выражения из цифр, знаков +, -, * и круглых скобок без пробелов, например ((2+3)*(5-1)). Вычислите его значение с помощью рекурсивного разбора.

Идея: Выражение в скобках состоит из двух подвыражений и оператора между ними. Рекурсивная функция разбирает левую часть (число или блок в скобках), считывает знак операции, разбирает правую часть и применяет оператор.
Задача 5

Проверка правильной скобочной последовательности (один вид скобок)

Условие: Дана строка длины до 104, состоящая только из символов ( и ). Проверьте рекурсивно, является ли она правильной скобочной последовательностью.

Идея: Передавайте в функцию текущий индекс i и счётчик открытых скобок balance. Если balance < 0 в любой момент — сразу NO. В конце строки проверяем, что balance == 0.

Рекурсивные функции с двумя и более ветвями (стиль ЕГЭ)

Задача 6

Число программ калькулятора (задача 23 из ЕГЭ)

Условие: Исполнитель преобразует число на экране с помощью двух команд:

  • Прибавить 1
  • Умножить на 2

Сколько существует программ, которые преобразуют число 2 в число 20, при этом траектория вычислений содержит число 10 и не содержит число 15?

Идея: Напишите функцию f(curr, target): если curr > target или curr == 15, возвращаем 0; если curr == target, возвращаем 1; иначе f(curr + 1, target) + f(curr * 2, target). Итоговый ответ равен f(2, 10) * f(10, 20).
Задача 7

Функция Аккермана

Условие: Даны два неотрицательных целых числа m и n (0 ≤ m ≤ 3, 0 ≤ n ≤ 10). Вычислите значение функции A(m, n):

  • A(0, n) = n + 1
  • A(m, 0) = A(m - 1, 1) при m > 0
  • A(m, n) = A(m - 1, A(m, n - 1)) при m > 0, n > 0
Идея: Прямая реализация трёх ветвей. Задача отлично тренирует понимание того, как работает стек вызовов при вложенной рекурсии (A(..., A(...))).
