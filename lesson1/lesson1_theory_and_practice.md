
## Теория: функции в Python

### 1. Зачем нужны функции и как их писать

Функция — это мини-программа со своим именем, которую можно написать один раз и вызывать сколько угодно.

```python
def say_hi(name):
    return f"Привет, {name}!"

print(say_hi("Маша"))  # Привет, Маша!

```

* `def` — создаёт функцию.
* **Параметры** (`name`) — «ячейки» для входных данных при описании функции.
* **Аргументы** (`"Маша"`) — реальные значения, которые мы передаём при вызове.

### 2. `return` против `print`

Это главный момент, на котором путаются новички:

* `return` выдаёт результат работы функции наружу — его можно положить в переменную, сложить с другим числом или вывести на экран.
* `print` просто печатает текст в консоль. Если у функции нет `return`, она вернёт `None` (пустоту).

```python
def plus_print(a, b):
    print(a + b)

def plus_return(a, b):
    return a + b

res1 = plus_print(2, 3)   # Напечатает 5, но res1 станет None
res2 = plus_return(2, 3)  # res2 станет 5, и с ним можно работать дальше

```

### 3. Значения по умолчанию и именованные аргументы

Параметру можно задать значение «на всякий случай». Если при вызове его не передать, возьмётся значение по умолчанию.

```python
def greet(name, emoji="👋"):
    return f"{name}, привет! {emoji}"

print(greet("Дима"))               # Дима, привет! 👋
print(greet("Дима", emoji="🔥"))   # Дима, привет! 🔥

```

### 4. Область видимости переменных

Переменные, созданные **внутри** функции, живут только пока функция работает. Снаружи их не видно. Переменные **снаружи** функции прочитать внутри можно, но менять их напрямую без необходимости не стоит — лучше передавать нужные данные через параметры и возвращать результат через `return`.

```python
tax = 10  # глобальная переменная

def calculate(price):
    result = price + tax  # result — локальная переменная
    return result

print(calculate(100))  # 110

```

### 5. Несколько аргументов через `*args`

Если заранее неизвестно, сколько чисел или слов передадут в функцию, помогает звёздочка `*` перед параметром — внутри функции они соберутся в кортеж (`tuple`), по которому легко пройти циклом или посчитать `len()` / `sum()`.

```python
def count_words(*words):
    return len(words)

print(count_words("кот", "пёс", "ёж"))  # 3

```
